# MegaCurrent/.github

Org-wide defaults for every `MegaCurrent` repository: pull request template,
issue templates, security policy and contribution rules. A repository that
ships its own copy of a file overrides the default here.

The workflow itself lives in `MegaCurrent/workflow`; clone that as the org
folder and it pulls this repository in as `org-github/` (the name differs
because the workflow repository has a `.github/` of its own).
