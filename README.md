# MegaCurrent/.github

Org-wide defaults for every `MegaCurrent` repository: pull request template,
issue templates, security policy and contribution rules. GitHub applies them
from this public repository to every repository in the organization that
does not ship its own copy of a file; the templates live under `.github/`
here because that is where GitHub reads them from.

The workflow itself lives in the private `MegaCurrent/workflow`; clone that
as the org folder and it pulls this repository in as `org-github/` (the name
differs because the workflow repository has a `.github/` of its own).
